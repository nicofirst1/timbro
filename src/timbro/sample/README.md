# Sample voice provenance

The packaged sample voice is `exemplars/` (move toward) and `contrast/` (move away).
This file records where each corpus file comes from.

Exemplar files are trimmed from posts on the 18F blog. Trimming removed front
matter, images and shortcodes, code blocks, and the weekly-ship email template,
and stripped inline link/bold/italic markup; the authors' wording is unchanged.
Contrast files are original illustrative slop written for this project.
